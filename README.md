# K92.3 Alexa — Second Date Update

**Goal:** Any listener says *"Alexa, bring up the Second Date Update"* and hears K92.3's Second Date Update immediately.

## What this is

A packet for Amazon's **Radio Skills Kit** (free, no-code, 38 countries). Once published, there is no skill to enable — listeners just say the station name and it plays.

## Files

- `skill.json` — interaction model (invocation names, sample utterances)
- `index.html` — landing page hosted at https://k923-second-date-alexa.netlify.app
- `SUBMISSION.md` — step-by-step Radio Skills Kit checklist for Obie
