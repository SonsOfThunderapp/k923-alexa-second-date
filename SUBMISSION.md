# Radio Skills Kit Submission Checklist — K92.3 Second Date Update

**Owner action required:** Only the station owner can submit, from their own Amazon developer account. Free. No code.

## Steps

1. Go to https://developer.amazon.com/alexa/console/ask and sign in (or create) an Amazon developer account.
2. Open the **Radio Skills Kit** console (search "Radio Skills Kit" in the Alexa console, or go to the Radio Skills Kit section).
3. Click **Add New Station**.
4. Fill in each step:
   - **Station Name:** K92.3 Second Date Update (write "Caps" not "C.A.P.S." so Alexa says it as a word)
   - **Alternative names:** K92.3, K nine two point three, WWKA, Second Date Update
   - **Call Sign:** WWKA
   - **Frequency:** 92.3 FM
   - **Location:** Orlando, FL
   - **Stream URL:** the K92.3 live MP3 direct link (found in Grow → Public page → Links tab on the station's hosting platform, or from Cox Media Group ops)
   - **Logo:** 1200×1200 PNG of the K92.3 mark
   - **Language:** en-US
   - **Category:** News & Information / Music
5. When it shows **Ready to Submit**, click Submit → Yes, Submit.
6. Amazon reviews (US is usually fast; GB/IE can take up to 3 weeks).
7. Once **Published**, test on any Echo: *"Alexa, play K92.3 Second Date Update"*.
8. Analytics appear in the console about 48 hours after publication.

## If Alexa plays the wrong station

Almost always a name clash. Add more alternate names in the console to steer her.

## Parallel paths (same data, more coverage)

- **TuneIn Broadcaster Portal:** https://tunein.com/broadcasters — 5–14 business days. Also puts K92.3 on Sonos, car systems, and hardware internet radios.
- **iHeartRadio:** K92.3 is already on iHeart (Cox Media Group). Confirm the Second Date Update is surfaced as a show page there.
- **Google Home:** routes through TuneIn by default, so the TuneIn listing covers Nest/Google speakers too.
